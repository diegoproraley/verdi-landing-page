🔧 Variáveis CSS

Como Usar

Todas as cores e valores estão centralizados em variáveis CSS. Para usar em um componente:

/* Exemplo: estilizar um botão */ .meu-botao { background: var(--verde-broto); color: var(--verde-noite); border: 1px solid var(--verde-broto); padding: 0.8rem 1.2rem; border-radius: var(--raio); transition: all var(--transicao); } .meu-botao:hover { background: var(--verde-claro); }

📋 Princípios de Design

1. Continuidade Visual

O formulário de entrega e o quadro de resumo (itens selecionados) formam uma unidade visual contínua. Ambos usam a paleta creme/branco com detalhes em marrom, criando uma transição suave e fazendo parecer um único passo.

2. Contraste & Legibilidade

Texto escuro sobre fundo claro; fundo claro sobre escuro. Mínimo de ratio WCAA AA (4.5:1 para texto, 3:1 para elementos grandes).

3. Hierarquia

Tamanhos, cores e pesos de fonte definem a importância. Títulos grandes em verde-noite; textos secundários em tinta-suave.

4. Modularidade

Componentes reutilizáveis usando a nomenclatura BEM. Todas as cores via variáveis CSS, nunca hardcoded.

5. Responsividade

Design mobile-first. Usa clamp() para fontes fluidas e min() para largura responsiva sem media queries.

✏️ Como Contribuir

Adicionar Nova Cor

  1. Defina no :root de css/styles.css:
    --minha-cor: #XXXXXX; /* descrição breve */
  2. Documente em DESIGN_SYSTEM.md
  3. Adicione preview em estilo.html
  4. Use em componentes: color: var(--minha-cor);

Criar Novo Componente

  1. Use nomes BEM: .componente__elemento--modificador
  2. Reutilize variáveis CSS sempre
  3. Documente uso e contexto
  4. Inclua preview aqui em estilo.html

Atualizar Paleta

Se uma cor mudar, atualize em:

  • ✅ css/styles.css (a variável)
  • ✅ DESIGN_SYSTEM.md (documentação)
  • ✅ estilo.html (preview visual)
